# CV Website 1 — Single-Page Scrolling CV

## Project Description
A professional, responsive, single-page CV website for Rida Fatima, a BS Computer Science student at Qarshi University, Lahore. The website presents personal information, education, career objective, technical skills, soft skills, courses, languages, and contact details in an organized layout.

## Design Prompt
Design a modern and professional single-page CV website using HTML, CSS, and JavaScript. The website should have a clean layout with vertical scrolling and no horizontal scrolling.

Use a consistent navy blue, golden yellow, black, light blue-grey, and warm white colour palette.

### Colour Scheme
- Navy Blue: `#17365D`
- Dark Blue: `#496D8E`
- Golden Yellow: `#D5A642`
- Black: `#000000`
- Dark Grey Text: `#30343B`
- Warm White Background: `#F8F6F2`
- Light Blue-Grey Blocks: `#E2E6EB`

### Layout and Design Requirements
- Create a navy blue header with the name "Rida Fatima" and navigation links.
- Add a hero section with a short introduction, action buttons, and a professional profile picture on the right.
- Display CV sections in separate white cards with rounded corners and subtle shadows.
- Use black headings with small golden yellow underline accents.
- Add numbered section badges from 01 to 08.
- Use light blue-grey blocks with a dark blue left border for paragraphs and information items.
- Keep education details, skills, courses, and languages compact and easy to read.
- Place the Contact Me section at the end of the page.
- Ensure the website is responsive on desktop, tablet, and mobile screens.
- Prevent horizontal scrolling while allowing vertical scrolling.
- Use JavaScript for smooth navigation and automatic updating of the footer year.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Main Sections
1. About Me
2. Education
3. Career Objective
4. Technical Skills
5. Soft Skills
6. Courses and Certifications
7. Languages
8. Contact Me

## Expected Result
A visually consistent, user-friendly, and professional CV website that presents the student's information clearly and follows the specified colour scheme and layout requirements.
